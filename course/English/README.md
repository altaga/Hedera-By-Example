## THE BRUTAL TRUTH
Most blockchain courses teach you how to build slow, expensive, and fragile "Minimum Viable Products". **This is not that course.** 

We focus on the **Hedera Hashgraph** ecosystem—a high-performance distributed ledger that delivers 10,000+ TPS, sub-second finality, and predictable fees. We use **Functional JavaScript** to build systems that are as elegant as they are powerful.

---

## THE INFRASTRUCTURE

### [01] PREREQUISITES
- **RUNTIME:** Node.js v18.0+
- **IDENTITY:** Hedera Testnet Account ([Get one here](https://portal.hedera.com))
- **ENVIRONMENT:** A `.env` file at the root containing `OPERATOR_ID` and `OPERATOR_PRIVATE_KEY`.

### [02] DEPLOYMENT
Clone the curriculum and initialize the environment:
```bash
git clone https://github.com/altaga/Hedera-for-Dummies.git
cd Hedera-for-Dummies
npm install
```
